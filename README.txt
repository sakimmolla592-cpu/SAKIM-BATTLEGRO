SAKIM BATTLEGROUND Android wrapper project


This project wraps the existing HTML game in an Android WebView, landscape and fullscreen.
It is a project source ZIP, not a compiled APK.\n
Build with Android Studio:
1. Install Android Studio and Android SDK.
2. Open this folder as a project.
3. Let Gradle sync.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK output is app/build/outputs/apk/debug/app-debug.apk.

If Gradle plugin or SDK versions need adjustment, use Android Studio's suggested sync fixes.
